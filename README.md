# 🐍 Змейка — Современная веб-игра

Классическая аркадная игра «Змейка», реализованная на React + TypeScript с современным дизайном, адаптивной вёрсткой и поддержкой мобильных устройств.

## 🎮 Описание

«Змейка» — это веб-версия легендарной аркадной игры, в которой игрок управляет змейкой, собирая еду и избегая столкновений со стенами и собственным телом. Чем больше еды собрано, тем длиннее змейка и выше счёт.

## ✨ Возможности

- 🎯 **Три уровня сложности** — Легко, Средне, Сложно (разная скорость движения)
- ⏸️ **Пауза и перезапуск** — в любой момент игры
- 🏆 **Система рекордов** — лучший результат сохраняется в localStorage
- 📱 **Мобильная поддержка** — свайпы и виртуальный D-Pad
- ⌨️ **Клавиатурное управление** — стрелки или WASD
- 🎨 **Современный дизайн** — тёмная тема, градиенты, анимации
- 📐 **Адаптивная вёрстка** — корректно отображается на любом экране
- 🚀 **Высокая производительность** — игровой цикл на requestAnimationFrame

## 🕹️ Управление

### Клавиатура (десктоп)

| Клавиша | Действие |
|---------|----------|
| `↑` / `W` | Движение вверх |
| `↓` / `S` | Движение вниз |
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `Esc` | Пауза / Продолжить |
| `Enter` | Начать / Перезапустить |

### Сенсорный экран (мобильные)

- **Свайп** по игровому полю — смена направления
- **D-Pad** — виртуальные кнопки управления (появляются автоматически на сенсорных устройствах)
- **Кнопка паузы** в центре D-Pad

## 🚀 Быстрый старт

### Предварительные требования

- [Node.js](https://nodejs.org/) версии 18 или выше
- npm (входит в состав Node.js)

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/snake-game.git
cd snake-game

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать для продакшена
npm run build

# Предпросмотр собранной версии
npm run preview
```

После запуска dev-сервера откройте [http://localhost:5173](http://localhost:5173) в браузере.

## 🎯 Правила игры

1. Нажмите **«Начать игру»** или `Enter`
2. Управляйте змейкой, собирая красную еду
3. За каждую съеденную еду — **+10 очков**
4. Змейка растёт с каждым съеденным фруктом
5. Игра заканчивается при столкновении со стеной или собственным телом
6. Выберите сложность перед началом для изменения скорости
